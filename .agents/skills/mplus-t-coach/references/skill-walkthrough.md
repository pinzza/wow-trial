## 报告结构（12 节）
1. P0 摘要 — 三层格式（核心问题 + 一句话解释 + 三个关键差距）
2. ✅ 做得好
3. ❌ 需要改进
4. 🔧 技能评估（全技能表 + emoji 评级）

11. 📅 下CD改进计划
12. 📝 教练笔记（孙青云口吻）

## 鹤僧手法诊断参考（基于绿绿月光基准）

| 技能 | 绿绿月光(+22执政团) | 诊断阈值 |
|------|---------------------|---------|
| 神鹤引项踢 | 478次 | ≥300次/全本 |
| 旭日东升踢 | 307次 | ≥200次/全本 |
| 神龙之赐 | 131次 | ≥100次/全本 |
| 复苏之雾 | ~1次 | 鹤僧基本不铺——学员用50+说明在玩龙僧 |
| 作茧缚命 | 16次 | ≥10次/全本 |
| 壮胆酒 | 8次 | 约8次机会/全本 |

复苏之雾次数是区分龙僧/鹤僧手法的核心指标。

## 核心诊断维度（施法时间轴对比）
- 三板斧节奏：旭日→幻灭→神鹤的序列是否完整
- 神龙之赐对齐：是否在团队大掉血前施放
- 减伤预判：壮胆酒/散魔功/作茧缚命在尖刺伤害前使用
- 读条占比：抚慰之雾/复苏之雾出现在高压期 = 浪费GCD
- 起手/转阶段：开怪起手是否正确（鹤僧直接三板斧）
