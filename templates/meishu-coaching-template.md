# 教练模式差距诊断书模板（M1 — 酒仙学员）

本模板用于 M1 教练模式的报告生成。结构与 X/T 系列同构，评估指标适配坦克三轴（伤害 + 自疗 + 减伤覆盖）。

> 使用时加载 mplus-coaching skill，读取本模板。

---

## 数据准备（生成前确认）

- [ ] 学习者的 WCL 报告已通过 v1_pipeline 抓取
- [ ] m2_standalone_summary.py 已生成 4 组文本
- [ ] 硬玩复仇的基准档案已可用（data/meishu/yingwan_benchmark_profile.json）
- [ ] 已有的历史快照已加载（用于趋势对比）
- [ ] 学习者的角色名/服务器已知
- [ ] （可选）events API 管线已完成——m_comparison.json 存在

**重点分析维度**：
- 接怪起手式：醉酿投开怪 → 火焰之息 → 酒醒入定 的序列是否完整
- 高压波次减伤链：壮胆酒/禅悟状态是否在尖刺前覆盖
- 活活血酒时机：是否在酒池变黄/红时及时消酒
- 爆发对齐：玄牛下凡是否对齐大波次

### ⏱ 技能深度解析

- 动态选题，根据本场日志实际差距选择 2-4 个专题
- 例如：酒池管理质量、减伤链规划、爆发循环密度、聚怪节奏、死亡复盘

### 💀 死亡分析

- 坦克死亡≈灭团——逐次深挖：
  - 致死技能：魔法/物理/尖刺/平砍累积
  - 减伤覆盖：死亡前 10 秒是否开了壮胆酒/禅悟状态/散魔功
  - 酒池状态：死亡前酒池颜色（绿/黄/红）——是否本可消酒救人
  - 自疗手段：玄牛之赐是否可拾取、明志灵药是否可用
  - 治疗缺口：死亡前 10 秒的治疗量是否足够

### 💬 师傅的话

1-2 段，硬玩复仇口吻（沉稳技术型，就事论事）。参考：
- 减伤 → "这个波次该开壮胆酒了"、"活血酒别省"
- 接怪 → "起手先给酒"、"火焰之息跟上"
- 死亡 → "这波不该死的"、"酒池红了没消"
- 表扬 → "这波接得不错"、"节奏可以了"
