# 教练模式差距诊断书模板（T1 · 织雾学员）

本模板用于 T1 教练模式的报告生成。
> 使用时加载 t1-coaching skill，读取本模板。
> 与 X1 模板同构，仅指标和技能名改为基于织雾武僧的治疗分析。

---

## 数据准备（生成前确认）

- [ ] 学习者的 WCL 报告已通过 v1_pipeline 抓取（含 healing-done 端点）
- [ ] m2_standalone_summary.py 已生成 4 组文本
- [ ] 绿绿月光的基准档案（lvlyue_benchmark_profile.json）已存在
- [ ] 已有的历史快照已加载（用于趋势对比）
- [ ] 学习者的角色名/服务器已知
- [ ] 知识卡片（孙青云教学体系）已加载

## 生成前检查

- [ ] 所有数据有明确来源
- [ ] 对比较为固定对标选手（绿绿月光）而非随机顶层
- [ ] 以孙青云口吻撰写诊断文字
- [ ] 修炼任务具体可执行，有量化目标
- [ ] 历史趋势已与上次报告对比
- [ ] 无空洞罗列，每条诊断有根因分析
- [ ] 评估指标以治疗量（HPS）为主，DPS 为辅
- [ ] 过量治疗率已纳入分析
- [ ] 减伤技能覆盖时间轴已考虑副本波次
